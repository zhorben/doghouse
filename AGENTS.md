# Project Memory & Agent Instructions — Doghouse Telekhany

This file is automatically loaded into the coding agent's context when working in `/home/ubuntu/doghouse`.

## 1. Project Context
- **Location:** г.п. Телеханы, Ивацевичский район, Брестская область, Беларусь.
- **Purpose:** Build a warm, insulated winter doghouse for 5 puppies (born August 11) right now, and for 2 medium-sized adult dogs (the mother + 1 grown puppy kept permanently) in the future.
- **Builders & Tools:** Beginner level (user + grandfather). Available tools: hand saw / jigsaw and cordless drill/driver (шуруповерт). All cuts and joints are designed for beginner execution without complex joinery or a miter saw.
- **Approved Budget:** **415,06 BYN** (for 100% new materials from local Telekhany enterprises and OMA/21vek).

## 2. File Responsibility Map (Strict Separation of Concerns)
Do not duplicate content across files. Each file has one clear role:

1. `README.md` — **Human Quick-Reference & Blueprint Showcase (auto-generated by `scripts/generate_blueprints.py`)**:
   - Displays the 5 blueprint sheets (`plans/01_...png` to `05_...png`), the 41-piece timber cut table, the sheet material cut summary, and the 415,06 BYN BOM table.
   - **Never edit `README.md` manually** — edit `scripts/generate_blueprints.py` and run `python3 scripts/generate_blueprints.py`.
2. `AGENTS.md` (this file) — **Agent Session Memory & Engineering Rules**:
   - Instructions for AI agents resuming work in future sessions.
3. `docs/DECISIONS.md` — **Architectural & Material Decision Log**:
   - Records every design choice made with the user and why alternatives (such as interior partitions, open skids, paving slabs, 30mm insulation, or exterior OSB) were rejected. Check this file before suggesting changes.
4. `docs/ASSEMBLY_GUIDE.md` — **Step-by-Step Beginner Build Manual**:
   - Detailed human assembly instructions from ground preparation (steel mesh) and wood impregnation safety to roof hinge installation, plus reference YouTube video timestamps.
5. `docs/PROCUREMENT_TELEKHANY.md` — **Local Purchasing & Delivery Guide for Telekhany**:
   - Exact contacts, addresses, phone numbers, and store product codes (`Код ОМА ...`) for ordering in Telekhany (ОАО «ТЗСИ», ГЛХУ «Телеханский лесхоз», 21vek.by pickup point, oma.by).
6. `scripts/generate_blueprints.py` — **Single Source of Truth for All Math, Geometry, Angles, Bin-Packing, and Costs**:
   - Computes all dimensions, trigonometric angles, stud edge heights $h(x)$, 1D/2D cut layouts, and `Decimal` costs, validates them with `assert` checks, and outputs `plans/*.png`, `plans/doghouse_blueprints_telekhany.pdf`, `plans/calculations_verified.json`, and `README.md`.
7. `viewer/index.html` — **Interactive 3D Model (Three.js)**:
   - Standalone browser 3D viewer with hinged roof slider and layer toggles.

## 3. Mandatory Rules for Future Sessions
- **100% Python Math:** Never calculate dimensions, angles, stud lengths, or BOM totals manually in chat. Always update `compute_doghouse_engineering_model()` in `scripts/generate_blueprints.py` and run `python3 scripts/generate_blueprints.py`.
- **No Code Comments:** Per global `AGENTS.md`, never write comments inside code files (`.py`, `.html`, `.js`). Use self-explanatory variable and function names.
- **Git Workflow:** The user syncs this project to their Mac via `git pull` from `https://github.com/zhorben/doghouse` (`main` branch).
